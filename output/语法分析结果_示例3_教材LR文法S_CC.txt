################ 三、分析结果 ################

-------------------- 1. LL(1) 分析结果 --------------------
改造后的文法：
Vn = { S, C }
Vt = { c, d }

P  = { S→CC ； C→cC ； C→d }

判定：分析表无多重入口，该文法是 LL(1) 文法。
分析步数：10 步
结论：分析成功：输入串 ccdd 是文法 S 的句子。

-------------------- 2. LR(0) / SLR(1) 分析结果 --------------------

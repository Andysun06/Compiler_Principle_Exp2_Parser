################ 三、分析结果 ################

-------------------- 1. LL(1) 分析结果 --------------------
改造后的文法：
Vn = { S, S′, E }
Vt = { a, b, else, if, then }
S  = S
P  = { S→a ； S→ifEthenSS′ ； S′→elseS ； S′→ε ； E→b }

  · S 的候选式有公共前缀 ifEthenS：提取为 S→ifEthenSS′

判定：存在 1 处冲突。
  · M[S′, else] 冲突：“S′→elseS” 与 “S′→ε” 都要求填入，该文法是 LL(1) 文法吗？
分析步数：18 步
结论：分析成功：输入串 if b then if b then a else a 是文法 S 的句子。

-------------------- 2. LR(0) / SLR(1) 分析结果 --------------------
项目集个数：10
LR(0) 分析表：存在 1 处冲突。
  · 状态 7，输入 else：移进-归约冲突（s8 与 r2）
SLR(1) 分析表：存在 1 处冲突。
  · 状态 7，输入 else：移进-归约冲突（s8 与 r2）
分析步数：16 步
结论：分析成功：输入串 if b then if b then a else a 是文法的句子。

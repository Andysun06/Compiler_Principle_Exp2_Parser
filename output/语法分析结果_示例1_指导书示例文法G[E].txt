################ 三、分析结果 ################

-------------------- 1. LL(1) 分析结果 --------------------
改造后的文法：
Vn = { E, E′, T, T′, F }
Vt = { i, +, *, (, ) }
S  = E
P  = { E→TE′ ； E′→+TE′ ； E′→ε ； T→FT′ ； T′→*FT′ ； T′→ε ； F→(E) ； F→i }

  · E 存在直接左递归：引入 E′，改写为 E→…E′、E′→…E′ | ε
  · T 存在直接左递归：引入 T′，改写为 T→…T′、T′→…T′ | ε

判定：分析表无多重入口，该文法是 LL(1) 文法。
分析步数：13 步
结论：分析成功：输入串 i+i 是文法 E 的句子。

-------------------- 2. LR(0) / SLR(1) 分析结果 --------------------
项目集个数：12
LR(0) 分析表：存在 2 处冲突。
  · 状态 4，输入 *：移进-归约冲突（r2 与 s8）
  · 状态 10，输入 *：移进-归约冲突（r1 与 s8）
SLR(1) 分析表：无冲突，该文法是 SLR(1) 文法。
分析步数：10 步
结论：分析成功：输入串 i+i 是文法的句子。
